# VLSI Design Internship - Task 2

## Introduction
This repository contains Verilog HDL programs developed as part of the VLSI Design Internship Task 2.

## Programs Included
- AND Gate
- OR Gate
- NOT Gate
- NAND Gate
- NOR Gate
- XOR Gate
- XNOR Gate
- Half Adder
- Full Adder

## Software Used
- Visual Studio Code
- Icarus Verilog
- GTKWave

## Simulation
All programs were compiled using Icarus Verilog and verified using GTKWave.
